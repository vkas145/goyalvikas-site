⚖️ Learn First: Solving Equationstap to open›

Imagine a weighing scale that's perfectly balanced. If you remove the same weight from BOTH sides, it stays balanced! That's the secret to solving equations.

🟰Equation: A statement that two expressions are EQUAL, like 2n + 1 = 99.
🔎Solving: Finding the value of the letter-number that makes both sides equal.
🎲Trial and error: Guess a value, check it, adjust, and try again — works but can be slow.
⚖️Balance trick: Do the SAME operation to both sides (add, subtract, multiply, divide) — the equation stays true!
🔄Undo it: To remove "+ 5" from one side, subtract 5 from BOTH sides. To remove "× 3", divide both sides by 3.
Try thisSolve 2n + 1 = 99. Subtract 1 from both sides: 2n = 98. Divide both sides by 2: n = 49
